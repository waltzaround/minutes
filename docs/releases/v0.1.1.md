## What's new

- Windows x64 installer, alongside an updated Mac build for Apple Silicon.
- Fixed Windows free-space detection, which could incorrectly report no disk space.
- Fixed fresh model downloads containing nested files, and retries after those downloads failed.
- Summary reliability checks now use the same validation and correction retry as meeting summaries. A recoverable answer no longer disables summaries for the whole app.
- **Settings → Advanced → Run system check again** now retests installed summary models. Use this after updating if summaries were previously unavailable.
- Fixed the Windows speaker-separation runtime build and strengthened the hardware recording test to require both microphone and system-audio tracks.

## Downloads

- **Windows:** Windows 10 or later, x64.
- **Mac:** macOS 14.6 or later, Apple Silicon.

These are unsigned preview builds; macOS builds are not notarised. Models download separately during setup. Existing models and meetings are retained when updating.

## Verification and limits

Windows checks passed for the default Rust suite, frontend tests and build, microphone and system-audio recording, speech detection, transcription, and the post-meeting transcription pipeline. The Vulkan runtime detected an RTX 5070 Ti. AI output still needs review: the real-model action extraction test missed an expected action in one run. Two-speaker diarization quality and the Windows installer upgrade flow still need broader testing.
