## What's new

- **Pause session** during a class or meeting break. Open the saved session and choose **Resume recording** to append another chunk, or **Finish and process** to complete it.
- Paused sessions survive app restarts. Normal app exit saves an active recording as paused; forced quits still use interrupted-recording recovery.
- Break time is excluded from recording timers and transcript timestamps. Resuming preserves earlier audio chunks.
- Speaker identification runs over the complete session when it is finished. Resumed transcription rebuilds provisional text without duplicate segments.
- **Import audio or video** from the New meeting screen. Minutes extracts the first audio track locally, then uses the existing transcript, speaker and notes workflow. Original files are left untouched.
- Saved transcript previews are visible when a recording resumes. Fixed voice-profile extraction selecting an earlier audio chunk after a resume.

## Import requirement

Audio/video import currently requires **FFmpeg installed separately**. On macOS, install it with `brew install ffmpeg`. On Windows, install FFmpeg and add its executable folder to PATH. If FFmpeg is missing, Minutes shows an installation message. A file with no audio, a damaged file, or a missing file is rejected without leaving an empty session.

## Downloads

- **Windows:** Windows 10 or later, x64.
- **Mac:** macOS 14.6 or later, Apple Silicon.

These are unsigned preview builds; macOS builds are not notarised. Models download separately during setup. Existing meetings and downloaded models are retained when updating.

## Verification and limits

Verified on macOS: microphone pause/reopen/resume with intact audio chunks and break time excluded; MP4 import using installed ASR/VAD models; resumed transcription without duplicate provisional segments; failed-import cleanup; frontend typecheck, tests and build; and the default Rust suite. The release workflow builds and tests macOS and Windows installers before publishing. New pause/import flows have not yet been exercised on Windows hardware. AI-generated speaker labels and notes need review.
